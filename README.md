# LookBack: A financial 'hindsight' tool

LookBack is a 'currently in development' fullstack web application that enables users to build an investment portfolio and see how such a portfolio would have performed from a chosen start date up to the present day.

## Tech Stack

**Frontend**: React + TypeScript + MaterialUI<br>
**Backend**: Java Spring Boot<br>
**Database & Migrations**: PostgreSQL<br>
**Tooling**: Docker + Git<br>
**External APIs**: Alpha Vantage (real-time financial data provider)<br>
